## Browsing this directory

You can read the guides and browse project links without an account. Project search and category filtering run in your browser. There is no model inference or API-key collection on this site.

## Optional analytics

This site uses Google Analytics measurement ID `G-6B7H863MFF` only after you select “Allow analytics.” It helps the operator understand page visits and usage. Google may process device, browser and network information as part of that service.

The analytics page URL excludes search parameters. Do not enter private or sensitive information into the project search field. The current site does not send project-search text as a custom analytics event.

Your analytics choice is stored in your browser’s local storage. Use “Analytics settings” in the footer to change it. Refusing analytics does not restrict access to the directory. Changing your choice stops future collection where controlled by this page; it does not erase data already processed by Google.

Read [Google’s privacy policy](https://policies.google.com/privacy) for information about its processing.
