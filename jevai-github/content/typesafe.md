## The company behind Jev

TypeSafe AI develops Jev, its first public System One model. It focuses on structured judgments that software can consume: selecting candidates, evaluating rubrics and judging conditions.

Jev Directory is an independent resource. For model availability, API access, billing and support, use TypeSafe’s own website and documentation.
